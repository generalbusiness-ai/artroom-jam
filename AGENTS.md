## Repository work

This is an example application on the Artroom platform, kept separate from
it.

- Depend on Artroom only through its published packages and the URL of a
  deployed room. Never import from Artroom's source tree or link to it as a
  workspace.
- Do not change Artroom to suit this application. When the application
  needs something the platform lacks, record it as a finding and file it as
  a request in Artroom's workroom.
- Track and review work in an Artroom room once Artroom can host this
  repository. Until then, spikes may start here; their review waits for
  that.
- Dependencies need a licence compatible with Apache 2.0. Tunes and samples
  heard in published audio or video are our own work.

User-facing notes, documentation and other communications prefer plain English,
per ISO 24495-1, for a technical audience.
